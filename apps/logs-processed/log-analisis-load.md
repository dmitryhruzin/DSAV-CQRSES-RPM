# Метрики *-load логів

26 файлів загалом; m7i / m7a / m7g × gp3 / io2 × m_cqrs / classical_cqrs × seq / load / middle-load.

Групування — за `req.id`. Для кожної групи підсумовуються тривалості всіх спанів із заданим іменем; відсутній спан = 0 мс.

`event.handle.durationMs` нормалізовано: для кожного спана з `durationMs ≥ 500ms` віднімається `N × 1000ms`, де `N = round(durationMs / 1000)` — кількість ретраїв VersionMismatch-логіки.

**Поля метрик:**

- **responseTime** — `http.request.durationMs` з telemetry-спана (не pino `responseTime`).
- **req_start → last event.handle end** — `max(event.handle.startedAt + durationMs) − http.request.startedAt`.
- Решта рядків = алгебра сум тривалостей спанів. Відсутній спан = 0.

Статистики (population): count, mean, median, p90, p95, variance σ², stdev σ, CV² = σ²/mean². Усі тривалості в **мілісекундах**.
